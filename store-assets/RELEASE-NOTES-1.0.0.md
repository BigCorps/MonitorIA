# MonitorIA Agent 1.0.0

Primeira versão estável do MonitorIA Agent preparada para distribuição oficial.

## Principais pontos

- instalação Windows x64 via Inno Setup;
- serviço `MonitorIAAgent`;
- pareamento com o painel MonitorIA;
- descoberta de câmeras IP, DVR e NVR na rede local;
- suporte a fluxos RTSP;
- processamento local do acesso às câmeras;
- credenciais de câmera mantidas localmente;
- FFmpeg congelado em dependências versionadas e verificadas por SHA256;
- assinatura de código SSL.com eSigner;
- instalador específico para Microsoft Store;
- instalação e desinstalação silenciosas;
- versão validada em DVR real.

## Arquivos

- `MonitorIA-Setup.exe` — distribuição direta pelo MonitorIA
- `MonitorIA-Store-Setup.exe` — Microsoft Store

Site: https://monitoria.cam
